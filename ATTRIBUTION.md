# ATTRIBUTION - CampusCoin

TechWiz 7 rules require full disclosure of any AI assistance used while building this project.

## Tools used

| Tool | What it was used for | Human review |
|------|----------------------|--------------|
| OpenCode (AI coding agent) | Scaffolding, component implementation, refactors | Every file reviewed, edited and understood by the student team before committing |
| Claude (AI assistant) | Design ideas, task breakdowns, code suggestions | Suggestions adapted to the SRS; all code re-written in our own JS style |
| AI image generation | Student-with-laptop hero illustration, logo concepts | Art direction and selection done by the team |
| Poolside `laguna-xs-2.1` (runtime AI, not a coding tool) | Answering student questions inside the app, from their own stored transaction figures | No code produced. Every prompt is assembled by our own server code; the model is told to answer only from the figures it is given and to refuse anything it cannot support |

## Rules we followed

- No AI-generated documentation - all docs written/rewritten by the team
- No ready-made templates copied unmodified - every component in this repo was written and reviewed for this project
- The team can explain every line of code in this repository on demand during the demo
- Reference material: approved mockups and the SRS document govern all design decisions

## AI services running inside the product

| Provider | Model | Where | Key handling |
|----------|-------|-------|--------------|
| Poolside | `poolside/laguna-xs-2.1` | `POST /api/ai/chat` - the Rix assistant on the Dashboard and Assistant pages | `POOLSIDE_API_KEY` is server-only, never a `VITE_` variable, and is never rotated or regenerated by any script |

Called through the OpenAI SDK with the base URL pointed at Poolside
(`https://inference.poolside.ai/v1`), because Poolside serves the OpenAI API shape.

The provider is only ever sent the signed-in student's own spending totals. No name,
no email address and no account id is included in a prompt.

*This file is updated whenever a new AI-assisted step is added to the project.*
